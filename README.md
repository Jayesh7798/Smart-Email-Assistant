# Smart Email Assistant

AI-powered email reply generator for Gmail. A Chrome extension adds an **AI Reply** button to Gmail's compose window, sends the email to a Spring Boot backend, and inserts a reply generated by the Google Gemini API (via Spring AI) straight into your draft.


## Features

- One-click AI reply inside Gmail's compose window
- Spring Boot REST API with controller and service layers
- Gemini integration through Spring AI
- React web interface to try replies outside Gmail
- Chrome extension (Manifest V3) that injects the button and inserts the generated text

## Tech Stack

| Layer | Technologies |
|-------|--------------|
| Backend | Java, Spring Boot, Spring AI, Maven |
| AI | Google Gemini API |
| Frontend | React 18, Vite |
| Extension | JavaScript, Chrome Extension APIs |

## Architecture

```
Gmail (Chrome Extension)  ──►  Spring Boot REST API  ──►  Spring AI  ──►  Gemini API
         ▲                                                                    │
         └────────────────────── generated reply ◄────────────────────────────┘
```

1. The extension reads the email content from Gmail and calls the backend.
2. The controller passes the request to the service layer.
3. The service builds a prompt and calls Gemini through Spring AI.
4. The generated reply is returned and inserted into the compose box.

## Getting Started

### Prerequisites

- Java 17+
- Maven
- Node.js 18+
- Google Chrome
- A Gemini API key from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone the repository

```bash
git clone https://github.com/Jayesh7798/smart-email-assistant.git
cd smart-email-assistant
```

### 2. Run the backend

Set your API key as an environment variable (never commit it):

```bash
# Mac / Linux
export GEMINI_API_KEY="your-key-here"

# Windows (PowerShell)
setx GEMINI_API_KEY "your-key-here"
```

Then start the server:

```bash
cd backend
mvn spring-boot:run
```

The API runs on `http://localhost:8080`.

### 3. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

### 4. Load the Chrome extension

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked** and select the `extension/` folder
4. Open Gmail, start a reply, and click **AI Reply**

## API

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/email/generate` | Generates a reply for the given email content |

**Example request**

```json
{
  "emailContent": "Hi, can we move tomorrow's meeting to 4 PM?",
  "tone": "professional"
}
```

**Example response**

```
Hi, 4 PM works for me. See you then.
```

## Configuration

| Variable | Description |
|----------|-------------|
| `GEMINI_API_KEY` | Your Google Gemini API key, read in `application.properties` |

```properties
spring.ai.google.genai.api-key=${GEMINI_API_KEY}
```
